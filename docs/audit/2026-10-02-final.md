# EduCore Final Audit — status of every finding at release 1.0.0

- Baseline: [`2026-09-25-baseline.md`](2026-09-25-baseline.md) (findings F-01 to F-27, re-verified 2026-10-01).
- Re-checked: 2026-10-02, against the 1.0.0 working tree, by reading the code, configuration and tests named in
  the evidence column. The test results are from the latest verification runs: 1 144 backend tests (590 unit,
  554 integration) with no failures, the attack suite (19 passed) and 168 frontend tests.
- Secret values are never reproduced in this document.
- Paths: `main/` = `src/main/java/com/educore/`, `test/` = `src/test/java/com/educore/`.

## Status legend

| Status | Meaning |
|---|---|
| FIXED | The defect no longer exists in the tree; the evidence names the code and, where possible, the test that pins it. |
| FIXED, OPERATOR STEP | Fixed in the tree; an action outside the repository remains (rotation of a value that is in Git history). |
| MITIGATED | The impact is closed or reduced; a named remainder is tracked in [`BACKLOG.md`](../BACKLOG.md). |
| BACKLOG | Still open; tracked with a backlog id. |

## Summary

- Of the 27 baseline findings, 25 are FIXED and 2 are FIXED, OPERATOR STEP (F-01, F-02: the leaked values remain in
  Git history until they are rotated and the history is purged). None is open.
- 25 later findings come from the threat model ([`THREAT_MODEL.md`](../security/THREAT_MODEL.md) R-01 to R-25),
  of which 12 are FIXED, 3 MITIGATED and 10 BACKLOG. The ZAP baseline found no High alert.
- The open items are listed under "Open items at release" with their backlog ids.

### Review findings closed during the phases

Independent reviews of the P4–P9 work found bypasses that were fixed before the phase closed. Each is recorded
with its decision:

- P4: unbounded anonymous bodies, Jackson enum coercion (`{"role":0}`), offset overflow, Unicode line
  breaks and formula triggers ([ADR 0023](../adr/0023-request-size-and-binding-limits.md)).
- P5: trusted-proxy blocks broader than /8, cache eviction resetting exhausted buckets, deny-cache failure
  behaviour, filter order ([ADR 0025](../adr/0025-perimeter-https-proxies-and-rate-limiting.md)).
- P6: mutable claimed files, lost accept-once marks, recovery of live runs, PII in Batch metadata
  ([ADR 0026](../adr/0026-ingestion-pipeline.md)).
- P9: lost unpublish under concurrent edits, slug races, dropped sitemap URLs
  ([ADR 0028](../adr/0028-public-course-catalog.md)).
