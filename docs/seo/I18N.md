# Public site languages

Decision (P9): the public site is published in **Turkish and English with the same route set**.

| Language | Prefix | Example | `<html lang>` | `og:locale` |
|---|---|---|---|---|
| Turkish (default) | none | `/`, `/courses`, `/courses/<slug>`, `/about`, `/faq`, `/privacy`, `/security` | `tr` | `tr_TR` |
| English | `/en` | `/en`, `/en/courses`, `/en/courses/<slug>`, `/en/about`, ... | `en` | `en_GB` |

Why Turkish at the root: the backend default (`educore.seo.languages`, first entry `tr`) and the backend
sitemap list the unprefixed URLs, so the root language must be the default language. English gets a path prefix
instead of a subdomain or a query parameter so that both versions are static files under one origin and one
certificate.

## Rules

- Every public page exists in both languages; the route list lives in `frontend/app/public-site/site-map.mjs`
  (`STATIC_PAGES`, `localizedPath`, `prerenderPaths`) and `frontend/app/routes.ts` (`publicPages('tr' | 'en')`).
- Every indexable page links its alternates: `<link rel="alternate" hreflang="tr|en|x-default">`, all absolute,
  `x-default` pointing to the Turkish URL. The canonical URL is the page's own language version (no
  cross-language canonical). The build sitemap repeats the alternates as `xhtml:link` elements.
- `<html lang>` is set by `app/root.tsx` from the URL (`app/public-site/document.ts`); `/app/**` and the SPA shell are
  `en` (the application screens are English).
- A visible language switcher in the header links to the same page in the other language (`hreflang` and `lang`
  attributes on the links; the current language has `aria-current`). On the not-found page it links to the other
  home page.
- All copy is in `frontend/app/public-site/copy.ts`, one typed object per language, written separately (not
  machine-translated). Glossary terms follow `docs/brand/BRAND_IDENTITY.md` section 11.2. Tests
  (`tests/public-copy.test.ts`) check both languages for the same facts and numbers, description lengths,
  question-form headings and the 60-word lead.
- Course data (name, term, instructor, description) is shown as the administrator entered it, on both language
  versions; it is not translated.
- Dates: `dd.MM.yyyy` for Turkish, `d MMM yyyy` for English, formatted in UTC at build time, with a
  machine-readable `<time datetime>`.

## Known gap

The backend `/sitemap.xml` (runtime, authoritative) lists only the unprefixed Turkish URLs and no `hreflang`
alternates. The build artefact `sitemap-static.xml` lists both languages. Adding `/en/**` URLs and
`xhtml:link` alternates to `SitemapController` is a backend change (BACKLOG).
